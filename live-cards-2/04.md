# Карточка 4 — Secret

Перед выполнением карточки — в SSH на VPS:

```bash
cd /opt/cloud-practice/flask-todo-k8s
kubectl config use-context kind-cloud-lab2
kubectl config set-context --current --namespace=cloud-lab2
kubectl get pods
kubectl get deployments
```

Это справочник для чтения после выдачи карточки. Меню ничего не применяет.
Блоки с --help и explain — справка, остальные команды выполняй осмысленно и по очереди.
Для nano: Ctrl+O, Enter — сохранить; Ctrl+X — выйти.
Правки Deployment применяются через apply и создают новые Pod при изменении шаблона.
Во время карточки не применяй все исходные файлы без необходимости.


Задание: добавить новый конфиденциальный параметр и передать приложению без изменения кода.
Базовый Secret уже есть. Создание ещё одного ключа выполняется при преподавателе.

```bash
kubectl get secret flask-todo-secret
kubectl explain deployment.spec.template.spec.containers.env.valueFrom.secretKeyRef
```

Добавь нужный ключ в stringData локального k8s/20-secret.yaml и ссылку на него в env Deployment. Имя переменной должно соответствовать реальному потребителю; Flask читает FLASK_ настройки через from_prefixed_env().
Не включай новый ключ или значение в публичный пример infra/secret.example.yaml.
Не вводи значение через --from-literal в команду, которая останется в истории.

Редактирование:

```bash
nano k8s/20-secret.yaml
nano k8s/40-deployment.yaml
```

После правок:

```bash
kubectl apply --dry-run=server -f k8s/20-secret.yaml -f k8s/40-deployment.yaml
kubectl apply -f k8s/20-secret.yaml -f k8s/40-deployment.yaml
kubectl rollout status deployment/flask-todo --timeout=180s
kubectl get secret flask-todo-secret
git check-ignore k8s/20-secret.yaml
```

Если менялось только значение существующего Secret, env текущих Pod не обновится: потребуется rollout restart. Изменение env в шаблоне Deployment само запускает обновление Pod.
Покажи ссылку secretKeyRef и наличие параметра без вывода значения. Для проверки Python используй bool(os.environ.get(...)) либо проверку соответствующего app.config, подставив имя выданного параметра при выполнении.
Secret сам по себе не гарантирует шифрование etcd; base64 — кодирование.
